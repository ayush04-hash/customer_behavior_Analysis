# Customer Behavior Analysis

An end-to-end data analytics project that analyzes customer purchasing behavior to identify patterns, trends, and actionable business insights.

## 🛠️ Tools & Technologies

* **Python – Pandas:** Data cleaning, preprocessing, transformation, and exploratory data analysis
* **SQL:** Data querying, aggregation, filtering, grouping, and business analysis
* **Power BI:** Interactive dashboards, KPIs, visualizations, and business insights

## 📊 Project Workflow

1. Cleaned and prepared the customer dataset using Pandas.
2. Performed exploratory data analysis to understand customer behavior.
3. Used SQL to answer business-related questions and identify key patterns.
4. Built an interactive Power BI dashboard to visualize important KPIs and insights.
5. Derived actionable insights from customer purchasing patterns.

## 🎯 Key Objectives

* Analyze customer purchasing behavior
* Identify popular products and categories
* Understand customer spending patterns
* Analyze discounts and purchasing trends
* Generate business insights through data visualization
